# How to Use This Vault

## Logging a Training Session
1. Go to `01 - Training Log/`.
2. Create a new note named by date (e.g., `2024-11-15`).
3. Insert the **Training Session** template.
4. Record your practice and observations.

## Adding a Technique
1. Go to `02 - Techniques/`.
2. Create a new note named by technique (e.g., `Ikkyo`).
3. Insert the **Technique Note** template.
4. Link it in your training logs using `[[Technique Name]]`.

## Exam Preparation
1. Check your rank requirements in `03 - Exam Program/`.
2. Use the checkboxes to track your progress.
3. Set a target date using the **Goal** template in `04 - Goals/`.

## Weekly Review
1. Create a note in `05 - Weekly Review/` every week.
2. Use the **Weekly Review** template for reflection.

## Keyboard Shortcuts
- New note: `Cmd/Ctrl + N`
- Command palette: `Cmd/Ctrl + P`
- Search: `Cmd/Ctrl + Shift + F`

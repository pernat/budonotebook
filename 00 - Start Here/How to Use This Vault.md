# How to Use This Vault

## Logging a training session

1. Go to `01 - Training Log/`
2. Create a new note — name it by date, e.g. `2024-11-15`
3. Open the command palette (`Cmd/Ctrl + P`) → **Insert template** → choose **Training Session**
4. Fill in what you practiced, who you trained with, and what you noticed

**Tip:** Even a few bullet points per session adds up over time.

---

## Adding a technique note

1. Go to `02 - Techniques/`
2. Create a new note — name it by technique, e.g. `Ikkyo`
3. Use the **Technique Note** template
4. Add a YouTube or other video link in the **Video demonstrations** section

**Linking techniques to training logs:** In your session note, type `[[Ikkyo]]` to create a link. Over time this builds a map of which techniques you've worked on and when.

---

## Tracking your exam preparation

- Open `03 - Exam Program/` and find your current kyu level
- Each page has checkboxes for every required technique — check them off as you feel confident
- Use the **Goal** template in `04 - Goals/` to set a target date for your next grading

---

## Weekly review

- Every week (Friday works well), create a note in `05 - Weekly Review/`
- Use the **Weekly Review** template
- Takes 10 minutes, builds long-term awareness of your progress

---

## Templates reference

| Template | Use it when |
|----------|------------|
| Training Session | After every class |
| Technique Note | Adding a technique to your library |
| Goal | Setting a new rank or skill goal |
| Weekly Review | End-of-week reflection |

To insert any template: `Cmd/Ctrl + P` → **Insert template** → pick from list.

## Useful keyboard shortcuts (Obsidian defaults)

| Action | Mac | Windows/Linux |
|--------|-----|---------------|
| New note | `Cmd + N` | `Ctrl + N` |
| Open command palette | `Cmd + P` | `Ctrl + P` |
| Open graph view | `Cmd + G` | `Ctrl + G` |
| Search vault | `Cmd + Shift + F` | `Ctrl + Shift + F` |
| Toggle reading view | `Cmd + E` | `Ctrl + E` |

## Recommended plugins (optional)

Install via **Settings → Community plugins → Browse**:

- **Dataview** — write queries like "show all sessions where I practiced Kote-gaeshi"
- **Templater** — auto-insert today's date in templates without typing it
- **Periodic Notes** — dedicated weekly/monthly note workflow
